# Auditable bounded KV-cache inference

2026-11-17 MYT. This is a runnable inference-engineering milestone, not a new
model, training improvement, throughput benchmark or production serving system.
The original full-forward implementation remains the numerical oracle.

## What was added

`transformer_core.inference.CachedByteDecoder` stores per-layer projected K/V.
It embeds and projects only new input positions, adds sinusoidal positions with
`offset=previous_length`, attends to old plus new keys using an absolute rectangular
causal mask, and applies the unchanged post-norm/FFN/output layers.
For a chunk of length C after P cached tokens, query i can attend exactly to
keys j where `j <= P+i`. This handles single-token decoding and chunked prefill.

A session deep-copies an existing eval model once. It does not mutate the source;
subsequent source training, configuration or `load_state_dict` changes cannot
invalidate that session. Create a new session to use new weights. `reset()` clears
only sequence state and retains the same snapshot. Source copying costs memory
and startup work, consciously traded for a simple auditable ownership boundary.

```python
import torch
from transformer_core.language_model import ByteLanguageModel
from transformer_core.inference import CachedByteDecoder, greedy_cached

model = ByteLanguageModel().eval()  # random weights here, API example only
session = CachedByteDecoder(model, max_context=64)
first = session.prefill(torch.tensor([[84, 104, 101]]))  # [1,3,256]
next_logits = session.append(torch.tensor([[32]]))  # [1,1,256]
chunk = session.append(torch.tensor([[97, 112]]))  # [1,2,256]
print(session.cache_info())  # shapes/length/KV tensor payload, no writable aliases
session.reset()
ids = greedy_cached(model, torch.tensor([[84, 104, 101]]), count=8, max_context=64)
```

Calls return logits for NEW positions only. `prefill` requires an empty session;
`append` requires a prefilled one. Inputs must be nonempty CPU int64 byte IDs in
0..255; batch size is fixed until reset. Validation/calculation failures do not
advance the cache. Execution disables autograd and external CPU autocast.
Supported weight dtypes: uniform float32 or float64. The installed loader preserves
the saved dtype and rejects mixed/unsupported types rather than silently casting.

## Context and generation semantics

- `max_context` is the caller's maximum TOTAL sequence length, not a sliding window.
  Overflow raises an error before modifying state. The trained checkpoint's context
  was64; our real-weight checks stop at64. No longer-context quality claim.
- `greedy_cached` enforces prompt length plus requested output count <= budget.
  It returns prompt+generated IDs, using the lowest ID on exact argmax ties. The
  final generated byte is returned but need not be forwarded into the cache.
- This is intentionally NOT a transparent replacement for old `generate()`, which
  samples multinomially and truncates/restarts positions for a64-byte window.
- No padding/masks for different lengths, eviction, EOS stopping, beam reordering,
  concurrent use of one session, GPU, quantization or HTTP server is implemented.
  Private cache/model mutation and custom architecture/hook changes are unsupported.

## Run and reproduce

From the repository, with the original CPU version for exact checkpoint recovery:

```bash
python -m pip install torch==2.14.1 --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[dev]'
# Explicit network step; original train/validation and license only.
python examples/recover_inference_checkpoint.py --output-dir results/inference-local
# Installed command, also works outside the source checkout with an absolute path.
transformer-cached-generate \
  --checkpoint results/inference-local/20261114-sinusoidal.pt \
  --prompt 'The application ' --count 16 --max-context 64
# Verifier rejects mismatched original checkpoint or pre-existing output file.
python examples/verify_inference.py \
  --checkpoint results/inference-local/20261114-sinusoidal.pt \
  --output results/inference-local/report.json
python examples/verify_inference.py \
  --checkpoint results/inference-local/20261114-sinusoidal.pt \
  --output results/inference-replay/report.json
cmp results/inference-local/report.json results/inference-replay/report.json
python -m pytest -q
python -m ruff check .
python -m ruff format --check .
```

Only open checkpoints from a trusted local source. Loading uses the restricted
`torch.load(..., weights_only=True)` route, not arbitrary Python checkpoint code.
`python -m transformer_core.inference_cli` exposes the same installed CLI.
No weights or downloaded prose are distributed. A local wheel was built without
network/dependency installation and tested from outside the checkout.

Final checks:163 CPU tests passed, including56 new inference/CLI checks; Ruff and
compileall passed. Python3.12.14/PyTorch2.14.1+cpu, deterministic one-thread verifier.
Missing optional NumPy emits one harmless warning; this code does not use NumPy.
A fresh-process report replay was byte-identical. A CLI dtype-preservation fix was
made during engineering QA; the report was regenerated after it, with unchanged
float32 numerical evidence. Earlier QA reports were retained locally, not reused
as independent observations. No old scientific artifact or training code changed.
